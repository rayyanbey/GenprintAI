1. START SERVER
   npm run dev
   → Opens http://localhost:3000

2. CREATE A DESIGN
   Go to: http://localhost:3000/design-studio
   • Add text layer
   • Add shape layer
   • Save design
   
3. VIEW DESIGNS
   Go to: http://localhost:3000/designs
   • See all your designs
   • Click Edit to modify
   • Click Delete to archive

4. TEST CHECKOUT
   • Add design to cart
   • Go to checkout
   • See preview at /checkout-preview/:id
   • Design mockup displays with price

5. TRACK ORDER
   Go to: http://localhost:3000/orders/:id
   • See order status timeline
   • When shipped: tracking number appears
   • Shows carrier & delivery estimate
